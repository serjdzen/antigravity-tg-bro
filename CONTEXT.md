## 1. 🎯 Миссия и Суть Проекта

**Antigravity TG** — это мобильный интерфейс управления локальной средой разработки **Google Antigravity** через Telegram-бота, развёрнутый на macOS / Linux.

### Зачем это сделано:
* **Управление кодом на ходу**: Полноценная разработка, запуск тестов, сборок и анализ локальных проектов прямо со смартфона из Telegram (текстом, голосом и скриншотами).
* **Мощь Google Antigravity**: Прямой доступ к флагманским моделям (Gemini 3.7 Flash Thinking, Gemini 3.1 Pro, Claude 3.7 Sonnet).
* **Непрерывная память**: Полное сохранение контекста диалогов, истории правок и доступ к файлам локальных проектов.

---

## 2. 🏛 Движки Выполнения (Engine Modes)

В системе реализовано 2 движка взаимодействия с AI, переключаемых в настройках (`/settings`):

```
          [ Telegram: Текст / Голос (Groq Whisper) / Фото / Документы ]
                                      │
                                      ▼
                             [ AntigravityBridge ]
                                      │
        ┌─────────────────────────────┴─────────────────────────────┐
        ▼                                                           ▼
[ 1. CLI Режим (Основной, по умолчанию) ]                 [ 2. Python SDK Режим ]
  • Прямой вызов ~/.local/bin/agy                           • Вызов google.antigravity SDK
  • Работает по подписке Google One AI Premium              • Требует GEMINI_API_KEY
  • Доступ ко всем квотам аккаунта                          • Прямое Python-управление
  • Нативный deny-list в settings.json                     • Политики Policy.confirm_run_command
```

### ⭐️ Почему CLI-режим является основным:
У пользователя активна официальная подписка Google One AI Premium / Antigravity Pro, привязанная к авторизации бинарника `agy` (`~/.local/bin/agy`). Использование CLI позволяет работать с высокими квотами без расхода платных API-токенов.

## 3. 🛡 2-Уровневая Модель Безопасности и Отказоустойчивость

> **Фундаментальное правило**: Мы **НЕ** модифицируем промпты пользователя искусственными системными текстами. Безопасность реализована на нативном уровне конфигурации CLI (`~/.gemini/antigravity-cli/settings.json`).

```
Пользователь отправляет задачу (текст / голос / фото)
                        │
                        ▼
[ Уровень 1: По умолчанию (100% Защита) ]
  • agy запускается БЕЗ флага --dangerously-skip-permissions
  • В settings.json активен allow-список с command(*) и mcp(*)
  • В settings.json активен жесткий deny-лист:
    (rm, rmdir, unlink, git reset --hard, sudo, dd, shutdown)
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
Безопасная операция               Попытка деструктивного действия (rm ...)
(создание/правка кода, git, сборка) │
        │                               ▼
Выполняется моментально           🛑 Блокировка на уровне ядра CLI:
                                  "Permission denied ... Matches deny rule"
                                        │
                                        ▼
[ Уровень 2: Разовый Override по кнопке ]
  • Под ответом всплывает инлайн-кнопка:
    [ ⚡ Разрешить разово (Force Override) ]  (или команда /force)
  • По нажатию:
    1. temporary_deny_override временно очищает deny в settings.json
    2. agy запускается с флагом --dangerously-skip-permissions
    3. Команда исполняется на диске
    4. В блоке finally исходный deny-список МГНОВЕННО возвращается на диск
```

### 🔒 Дополнительные механизмы отказоустойчивости:
1. **Startup Safety Guard (`ensure_deny_integrity()`)**:  
   При каждом запуске бота в `main.py` проверяется целостность `deny`-правил. Даже если компьютер экстренно выключится посреди выполнения команды, при включении защита восстановится на 100%.
2. **Экстренная остановка (`/stop`)**:  
   Команда `/stop` принудительно отправляет `SIGTERM`/`terminate` в запущенный процесс `agy`, мгновенно освобождая ветку диалога.
3. **Атомарная запись `sessions.json`**:  
   Запись сессий производится через `.tmp` файл с подменой через `os.replace` — исключает риск повреждения JSON-файла.

## 4. 🎙 Голосовой Движок (Groq Whisper Large v3 Turbo)

* **Модуль**: `src/engine/voice_transcriber.py`.
* **Стек**: Groq LPU + модель `whisper-large-v3-turbo` через асинхронный `aiohttp`.
* **Скорость**: **~0.3–0.5 секунды** на распознавание голосового сообщения любого размера. Нагрузка на систему — 0%.
* **Словарь подсказок (`data/whisper_prompt.txt`)**:  
  Модуль динамически считывает файл словаря (`Antigravity, amoCRM, n8n, Astro, TypeScript, Next.js, Docker, Supabase, Wordstat...`) и передает его в параметр `prompt` модели Whisper для безупречного распознавания IT-терминов.

## 5. 📂 Обмен Файлами и Мультимодальность (Vision & Files)

### 📥 1. Приём Фото, Скриншотов и Документов (Telegram ➔ Сервер):
* **Изолированная папка (`data/uploads/`)**: Все присланные файлы сохраняются отдельно и не загрязняют дерево файлов рабочего проекта.
* **Мультимодальность Gemini 3.7 Flash Thinking / 3.1 Pro**: Бот передает абсолютный локальный путь к файлу. Модель напрямую считывает изображение с диска, понимает геометрию, цвет, верстку и текст ошибок на скриншотах.

### 📤 2. Отправка Файлов и Картинок Пользователю (Сервер ➔ Telegram):
* **Авто-доставка вложений (`extract_attachment_paths`)**: Если агент в ответе генерирует изображение или файл и указывает ссылку `![alt](path)` или `[файл](file:///path)`, бот автоматически отправляет реальный бинарный файл (`send_photo` / `send_document`) в Telegram.
* **Прямое скачивание (`/get <путь>`)**: Отправляет любой файл по относительному или абсолютному пути на хосте (до 50 MB).

## 6. 🎨 Telegram UX, Интерфейс и Меню

### 📱 Меню Команд Telegram:
* 💬 `/chats` — Ветки диалогов, создание новых чатов, история и переименование.
* 📁 `/project` — Навигатор по папкам на машине с инлайн-кнопками.
* 🧠 `/model` — Фокус только на выборе моделей (Gemini 3.7 Flash, Pro, Claude) и Thinking Effort (High, Medium, Low, Off).
* ⚙️ `/settings` — Безопасность (Ask vs Full Auto), режим движка (CLI vs SDK) и кнопка очистки папки `data/uploads/`.
* 📊 `/status` — Текущий статус сессии, активный проект, модель и количество временных файлов.
* ❓ `/help` — Справка по всем возможностям бота.
* 🛑 `/stop` — Экстренное прерывание текущей задачи.

### ⚡ Live Streaming (`src/bot/utils/streamer.py`):
* Потоковый вывод ответа через редактирование сообщения на месте (`edit_message_text`).
* Троттлинг 1.4 секунды для предотвращения `FloodWait` лимитов Telegram.
* Парсер Markdown в Telegram HTML с поддержкой цитат, блоков кода и fallback на чистый текст при сломанных тегах.

## 7. 🍏 Фоновый Демон macOS 24/7 (`launchd` LaunchAgent)

* **Имя в macOS**: `antigravity-tg-daemon` (отображается в «Настройки -> Объекты автозагрузки»).
* **Управление**: Скрипт `scripts/service.sh` (`install`, `status`, `restart`, `logs`, `stop`).
